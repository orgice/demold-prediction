# 센서 이름 변경·숨기기·삭제 API 요청 (프론트 → 백엔드)

작성 2026-11-18 · 프론트 화면: 센서 데이터 › 센서 칩 오른쪽 **⋮ 아이콘** (편집 권한 이상) — `src/components/SensorChipMenu.tsx`

## 왜 필요한가

센서 데이터 화면의 센서 칩이 MAC(`CDE0`, `640447` …)으로만 보여 어느 위치의 센서인지 알기 어렵고,
시험용·고장 센서를 목록에서 빼거나 잘못 들어온 센서 데이터를 지울 방법이 없습니다.
지금은 `.env`의 `HIDDEN_SENSORS`로만 숨길 수 있어 화면에서 바꿀 수 없습니다.

프론트는 아래 계약대로 만들어 두었고 지금은 브라우저 목업(`src/api/sensorsMock.ts`)으로 동작합니다.
API가 준비되면 `src/api/sensors.ts`의 `SENSORS_IS_MOCK`를 `false`로 바꾸면 연결됩니다.

## 1. 센서 설정 테이블 (예: `sensor_meta`)

| 컬럼 | 타입 | 설명 |
|---|---|---|
| `mac` | `VARCHAR(32)` PK | 센서 MAC |
| `label` | `VARCHAR(50) NULL` | 사용자가 붙인 표시 이름. 없으면 화면은 MAC을 보여 줌 |
| `hidden` | `BOOLEAN` 기본 0 | 목록에서 숨김 (데이터는 그대로) |

`GET /api/sensors` 응답 항목에 `label`, `hidden`을 추가하고, **숨긴 센서도 목록에 포함**해 주세요 (화면이 `hidden`으로 걸러 냄, 칩 끝 '숨긴 센서 N개'에서 다시 보이게 할 수 있어야 함).
기존 `HIDDEN_SENSORS`는 그대로 두되(환경 설정으로 영구 제외), 화면 숨김은 이 테이블로 합니다.

## 2. `PATCH /api/sensors/{mac}` — 이름 변경 / 숨기기

```json
요청  { "label": "B동 슬래브 1번" }   // null 또는 "" 이면 MAC으로 되돌림
요청  { "hidden": true }              // false 면 다시 보이기
응답  SensorInfo (GET /api/sensors 의 한 항목과 같은 모양, label·hidden 포함)
```

- 둘 중 보낸 필드만 바꿉니다. 50자 제한, 앞뒤 공백 제거. 데이터가 없는 MAC은 404.
- 숨겨도 회차 연결(`pour.sensors`)과 예측 계산에는 영향이 없어야 합니다.

## 3. `DELETE /api/sensors/{mac}` — 이 센서의 측정 기록 전체 삭제

```json
응답  { "mac": "CDE0", "rows_deleted": 123456, "pours": [3, 4] }   // pours: 이 센서가 연결돼 있던 회차 id
```

처리 순서 제안:
1. `pressure` 또는 `moisture` 원본에서 `mac` 행 삭제
2. `sensor_10min`에서 `mac` 행 삭제
3. `sensor_meta` 행 삭제
4. 연결 회차의 `pour.sensors`에서 뺄지 남길지 결정 (아래 협의) 후 `maturity.clear_cache()`
5. 한 트랜잭션으로 처리, 실패 시 전부 되돌림

## 4. 협의가 필요한 점

- **연결 회차 처리**: 삭제한 센서를 회차의 연결 센서 목록에서 자동으로 뺄지, 남겨 두고 "데이터 없음"으로 보일지.
  프론트 확인 창은 "연결 회차의 그래프와 강도 예측이 바뀌거나 예측할 수 없게 됩니다"라고 안내합니다.
- **삭제 범위**: 센서 전체 삭제만 둘지, 기간을 정해 일부만 지우는 기능이 필요한지 (일부 삭제는 회차 설정의 '측정 구간 제외'로 대신할 수 있음).
- **권한**: 이름 변경·숨기기는 편집 이상, 삭제는 관리자만으로 할지. 프론트는 지금 편집 이상에게 세 버튼을 모두 보여 줍니다.
- **삭제 이력**: 되돌릴 수 없는 작업이므로 변경 기록(audit)에 남길지.
- **CSV 업로드 기록과의 관계**: 센서를 지우면 그 센서가 들어 있던 `upload_log` 기록은 남길지 (`docs/csv-data-api-request.md`와 함께 검토).
