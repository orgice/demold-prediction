# 거푸집 탈형 시점 예측

폴리텍 AI/AX엔지니어 과정 기업연계 프로젝트 (협력 기업: 알루미늄 거푸집 제조사).
알루미늄 거푸집 센서(내부온도·측압·수분)와 공시체 압축강도 시험 결과로 콘크리트 압축강도를 예측하고,
벽체 해체(5 MPa)·슬래브 해체(14 MPa) 가능 시각을 알려 주는 웹앱입니다.
LLM 에이전트(도구 호출 + 해체 가이드라인 RAG)로 해체 시점을 대화로 물어볼 수도 있습니다.

> 협력 기업의 센서 데이터, 압축강도 시험 결과, 받은 문서는 이 공개 저장소에 포함되어 있지 않습니다.
> 코드는 같은 형식의 데이터를 넣으면 동작합니다.

## 예측 방법 요약

1. 센서 내부온도로 적산온도 M = Σ max(T − 0℃, 0)·Δt 를 계산
2. 과거 회차 현장양생 공시체로 맞춘 쌍곡선형 강도 곡선에서 강도를 읽음 (예측 회차는 학습에서 제외)
3. 그 회차의 공시체 결과(예: 1일)가 나오면 곡선을 회차에 맞게 보정
4. 미래 온도는 직전 24시간 패턴 반복으로 가정해 5·14 MPa 도달 시각과 90% 범위를 계산

협력사 시험 타설 5회차로 회차 단위 교차검증한 결과, 3일 이내 강도 오차(RMSE)는
보정 전 1.6 MPa, 1일 공시체로 보정하면 0.7 MPa였습니다.

## AI 상담 (LLM 에이전트)

- OpenAI 호환 LLM 서버(tool calling 지원)에 연결해, 모델이 예측·회차 목록·온도·가이드라인 검색 도구를 골라 부르고 결과를 설명합니다.
- 강도·시각 숫자는 LLM 이 만들지 않고 모두 적산온도 모델이 계산합니다.
- 가이드라인 검색은 하이브리드 검색입니다: BM25 키워드 검색(한국어 bigram, 직접 구현) + 팀 서버 임베딩(qwen-embedding) 의미 검색을 순위 합치기(RRF)로 묶습니다. 임베딩 서버가 안 되면 키워드 검색만 씁니다.
- 색인은 저장소에 든 팀 요약본(`webapp/backend/knowledge/`)을 기본으로 씁니다. 국토교통부 원문 가이드라인은 재배포 금지라 저장소에 없으며, 원문 PDF로 색인을 만들면(`webapp/backend/scripts/build_guideline_index.py`) 그것을 먼저 씁니다.
